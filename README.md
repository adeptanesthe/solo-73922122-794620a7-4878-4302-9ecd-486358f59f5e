# 剪辑接缝跳听台（Clip Lab）

给剪辑师剪掉访谈停顿后按**成片时码**跳听接缝、并在**不真正改剪法**的前提下
试剪一块、对照两种剪法全片峰值的网页工具。Flask + NumPy 实现，上传单声道
PCM16 WAV，按 **4096 样点**分块，可撤下/恢复任意块；输入成片 0 基样点号，
显示对应原块与块内偏移，并返回从该处到块末的 PCM16 WAV 试听。

## 它解决什么问题

剪完之后，低通滤波必须作用在“保留样点拼接后的序列”上，而不是在原时间轴上
滤波后再删块（两种结果不同）。本工具把每块对一阶低通的作用预先做成摘要，
撤块时只改摘要，跳听时用摘要恢复滤波器状态，再只读命中块的原始样点。

撤下一块后，后面的保留块换了入块状态，可能出现更高的峰值。试剪功能在上传
摘要之上，对“当前剪法”和“切换某块保留状态后的剪法”分别求全片峰值，
各标一处峰值所在的成片样点号，全程不读原始样点、也不改动实际剪法。

### 两个树，两个 O(log N)

一阶低通 `y[n] = a·y[n−1] + (1−a)·x[n]`（零状态起步，全程 float64 不取整）
对一块长度 L 的样点，等价于关于入块状态的仿射变换：

```
y_out = w·y_in + b,  w = a^L,  b = (1−a)·Σ a^(L−1−n)·x[n]
```

| 结构 | 存什么 | 用途 |
|---|---|---|
| Fenwick 计数树 | 每块保留样点数（撤下=0） | 成片样点号 → 原块/块内偏移（前缀和 + 第 k 个位置） |
| 仿射线段树 | 每块 (w,b)；撤下块放恒等 (1,0) | 前缀复合得到“进入某块前”的滤波器状态 |

- **撤下/恢复一块**：Fenwick 单点增减 + 线段树换叶子并向上重算，只碰 O(log N)
  个摘要，原始样点读取 0 次（页面会实时显示这两个计数）。
- **跳听**：Fenwick 定位块号/偏移（O(log N) 摘要），线段树前缀查询拿到入块
  状态（O(log N) 摘要），然后**只读 1 个原始块**，从入块状态逐样点递推到块末，
  量化输出 PCM16 WAV。

### 试剪峰值：直线包络 + Li Chao 树

块内第 n 个样点的滤波输出关于入块状态 s 是一条直线
`y[n] = w[n]·s + b[n]`（`w[n]=a^(n+1)`，`b[n]` 由零状态同一递推展开）。
上传时对每块建好两组“直线最大值查询”结构（上包络、下包络），试算时：

1. 按保留块走一遍仿射状态流（用已有块摘要 `(w,b)`），得到每块入块状态 s；
2. 对上包络查 `max_n y[n]`、下包络查 `min_n y[n]`，取绝对值更大者为该块峰值；
3. 全片取最大，并用前缀计数把 `(原块号, 块内偏移)` 换算成成片样点号。

**为什么用 Li Chao 树而不是交点凸壳**：`w[n]=a^(n+1)` 在 n 较大时会在
float64（甚至 80 位 longdouble）下溢到 0、相邻斜率差发生灾难性抵消，基于
交点除法或斜率差叉乘的凸壳会失真。零状态一阶低通恒有 `|s| ≤ 32768`，所以
只在固定连续域 `[-32768, 32768]` 上建 Li Chao 树；插入和查询**只比较直线
在具体点的取值**，没有减法抵消、没有交点计算，对任意 `0 ≤ a < 1`（含
a=0 的水平线退化）都数值稳健。树深取 22，叶子区间宽 0.015625，给出可证明
的离散误差上界 0.0078125（< 0.01，穷举实测为 0）；用 dict 稀疏存储，
4096 条线通常只占几个节点，整工程包络内存仅十几 KB。

试算的工程语义：

- 峰值取**量化前** float64 的最大绝对值，零状态起步；没有保留样点返回“空片”。
- 每个保留块各查一次上壳、一次下壳，**单块比较总数（上+下）≤ 32**（实测
  通常 ≤ 18），全程零原始样点读取。
- 试算**不改剪法**，在锁外计算，期间另一窗口仍可撤块/恢复。
- 每次真正的撤/恢复让剪法版本号 +1。试算前后各取一次版本号，期间剪法变过
  （即使已经改回）就返回 409，提示“请重新试算”，不展示作废结果。
- 试算仅用于**至多 512 块**的录音，超过直接 400 提示。

## 启动（Docker Compose）

```bash
docker compose up --build
# 浏览器打开 http://localhost:5000
```

容器单 gunicorn worker + 多线程（工程状态在进程内存，多 worker 会互不可见），
上传的裸 PCM 落在命名卷 `clip-data`（容器内 `/data`）。

不用 Docker 的本地跑法：

```bash
pip install -r requirements.txt
python tools/make_sample_wav.py sample_audio/interview_demo.wav   # 已附带可跳过
flask --app app.main run
```

## 试用流程

1. 首页选 `sample_audio/interview_demo.wav`，填系数 a（0 ≤ a < 1，如 0.9），上传。
2. 工程页 40 个块按网格展示；红色块即示例里的停顿块（#3、#4、#9、#16、#17、
   #25、#32），点任意块撤下/恢复，下方显示本次访问的摘要数与原始块读取数。
3. 在“成片时码跳听”输入 0 基样点号（页面标注当前有效范围），点定位：
   - 显示原块号、块内偏移、原始录音样点号、试听时长；
   - 播放器加载从该样点到块末的滤波后 PCM16 WAV；
   - 越界（负数或 ≥ 保留样点数）返回 400，页面红条提示重新选择。
4. 在“试剪峰值对照”输入一个块号，点试算：
   - 表格并排显示**当前剪法**与**切换该块保留状态**两种成片的保留样点数、
     量化前全片峰值和峰值所在成片样点号（含原块号/块内偏移/原始样点号）；
   - 撤光全部样点的剪法显示“空片”；试算不改变实际剪法，可放心反复试不同块；
   - 若试算期间在另一窗口改了剪法（哪怕改回），页面提示重新试算。

## 验证结果

在 Python 3.11 + NumPy 2.4 + Flask 3.1 下执行（命令均在仓库根目录）：

```bash
PYTHONPATH=. python tests/test_core.py     # 引擎断言，全部通过
PYTHONPATH=. python tests/test_web.py      # Flask 路由，全部通过
PYTHONPATH=. python tests/test_trial.py    # 试剪峰值路由，全部通过
PYTHONPATH=. python tests/e2e_http.py      # 起服务后的真实 HTTP 端到端，全部通过
```

关键核对点：

- **试剪峰值精度**：随机录音、`a ∈ {0, 0.3, 0.85, 0.99}`、随机撤块，对两种剪法
  分别把试算结果与“先拼接保留样点、零状态逐样点滤波（float64 不取整）”的参考
  实现比对——所报峰值、标记样点号处的实际绝对幅度、真实峰值三者两两差
  **≤ 0.01 个 PCM16 量化单位**（实测多为 0，最差 ~1e-12）。覆盖 a=0 的水平线
  退化、非整块结尾、空片与“空片下试算恢复一块”等边界。
- **数值稳健性**：`a^n` 在 float64 下溢（如 a=0.3、n≈618 后斜率为 0）的极端
  情形下，Li Chao 树在 4096 线全长度穷举中仍零误差；基于交点/叉乘的凸壳在同
  数据上会偏差数千单位，已弃用。
- **比较预算**：每个保留块上壳+下壳各查一次，单块比较总数 ≤ 32（实测常 ≤ 18）；
  试算全程原始块读取为 0，且不改变剪法与剪法版本号。
- **并发与过期**：试算在锁外计算，期间另一窗口撤下再恢复（版本号 +2、剪法
  外观复原）仍被识别为过期，路由返回 409 提示重算。
- **512 上限**：513 块录音试算返回 400 并提示，512 块恰好允许。
- **量化误差（跳听）**：随机录音、随机撤块（含非整块结尾），对每个保留块块首
  与块内随机偏移做跳听，与参考实现逐样点比对，最大差 0（要求 ≤ 1 个量化单位）。
- **访问复杂度**：撤下/恢复的原始块读取恒为 0、摘要访问随 log N 增长；跳听
  原始块读取恒为 1。
- **格式**：非 WAV、立体声、非 16 位、a 越界/非数字全部拒绝；试听 WAV 为
  单声道 PCM16、同采样率、帧数等于“到块末”样点数。

## 约定与边界

- 上传上限 128 MiB；仅接受单声道、16-bit PCM WAV。
- 工程保存在服务进程内存（重启失效），原始 PCM 落盘在 `/data`。
- 末块不足 4096 样点时按实际长度处理，摘要与计数自然兼容。
- a=0 时滤波器退化为直通，已专项测试。

## 余下工作

- 本环境没有 Docker 守护进程，**镜像未在此处实际构建/运行**；Dockerfile 与
  compose 已按 gunicorn 单 worker 写好，全部功能改用本地 Flask + 四套 Python
  测试（含真实 HTTP 端到端）验证，需在有 Docker 的机器上
  `docker compose up --build` 复核一次。
- 工程状态未持久化到磁盘/数据库，服务重启需重新上传；多副本部署需要外置存储。
- 试听固定输出“到块末”，没有跨块连续试听与波形可视化；试剪只给峰值数值与
  样点号，没有在波形图上直接标注峰值位置。
- 大文件上传与长录音只有 128 MiB 大小限制，没有分片上传和进度展示。
